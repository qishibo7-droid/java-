# example1 解题过程总结

对应代码：`practice/example1.java`
涉及知识点：for 循环、取余与整除拆位、累加、布尔比较

## 一、这道题在做什么

找出 1000 以内所有"水仙花数"：一个数每一位数字的三次方之和，等于它本身。

例：153 → 1³ + 5³ + 3³ = 1 + 125 + 27 = 153 ✓

## 二、通用过程：把一个数的每一位拆出来

| 步骤 | 做什么 | 以 i = 153 为例 |
|---|---|---|
| 1 | 把原数复制给临时变量 | `c = i` → c = 153 |
| 2 | 取最低位：`c % 10` | 3 |
| 3 | 把这一位立方后累加 | b = 27 |
| 4 | 去掉最低位：`c = c / 10` | c = 15 |
| 5 | 重复 2~4，直到 `c == 0` | 5³ → b = 152；1³ → b = 153 |
| 6 | 累加结果和原数比较 | `b == i` → 153 是水仙花数 |

循环骨架（位数未知也能用）：

```java
int a = 0, b = 0, c = i;
for (; c != 0; c = c / 10) {
    a = c % 10;       // 取出当前最低位
    b += a * a * a;   // 用它做点事
}
if (b == i) System.out.println(i);
```

## 三、两个容易踩的点

- **必须先复制原数**：拆位过程中 `c` 会被改成 0，不复制就没法再和 `i` 比较
- **循环边界**：题意是"1000 以内"，代码写的是 `i <= 1000`，会把 1000 也试一遍。不影响结果（下面有实测），但写 `i < 1000` 更贴合题意

## 四、代码验证（实测）

`java example1` 输出：

```
153
370
371
407
```

再用探针把 0~999 全部试一遍核对：

```
0~999 里满足立方和相等的数: [0 1 153 370 371 407]
1000 的立方和 = 1，是否等于本身: false
```

- 三位数里就这四个，和题目输出一致
- 0 和 1 也满足（0³ = 0、1³ = 1），代码从 100 开始，所以没打印出来

## 五、带出的通用结论

1. **取个位 `% 10`、去个位 `/ 10`** 是拆数字的通用组合，配循环就能从低位到高位走遍每一位
2. 拆位前先**备份原数**，凡是做完运算还要拿原数比较的题都适用
3. 先用小范围验证逻辑，再放到题目要求的范围里跑

## 六、解题固定套路

1. 读题，把条件翻译成一句可验证的判断（这里是「各位立方和 == 本身」）
2. 想清楚"每一位怎么拿到" → `% 10` 和 `/ 10`
3. 外层循环给候选数，内层循环拆位
4. 先跑小范围核对结果，再跑题目要求的范围
