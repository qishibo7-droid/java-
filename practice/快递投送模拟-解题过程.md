# 快递投送模拟 解题过程总结

对应代码：`practice/快递投送模拟.py`
语言：Python 3.14（原件在桌面项目 `快递投送模型\python代码\`）
涉及知识点：随机种子、生成树、邻接矩阵、带权图、随机任务生成
用途：路网 + 快递任务的随机算例生成器，后续用 Java 还原

## 一、这段代码在做什么

一次生成一个"快递投送"问题的随机算例，四步：

| 步骤 | 产出 | 本次运行（SEED = 2024） |
|---|---|---|
| 1 | 随机生成一棵 10 节点的生成树 | 9 条边 |
| 2 | 按概率补边，做成连通带权路网 | 邻接矩阵 `Matrix` + 权值矩阵 `Weight` |
| 3 | 给节点随机派快递任务 | `P(优先): [3, 4]`、`O(普通): [2, 5, 7, 9]` |
| 4 | 打印结果 | 四段输出 |

## 二、通用过程

1. **固定种子**：`SEED = 2024`，保证每次跑出来的算例一样，方便复现、方便对比算法结果
2. **先生成树**（保证连通、不会有孤立点）：
   - 把节点顺序 `shuffle` 打乱，起点先入树
   - 每次从**已在树里**的节点中随机挑一个当父节点，把新节点接上去
   - 9 个新节点 → 9 条边 = `NODES - 1`
3. **再补边**：只遍历上三角（`j` 从 `i + 1` 开始），没连通的按 `EXTRA_EDGE_P = 0.70` 概率随机连通，赋值时**两处都写**保证对称
4. **赋权**：另开一个 `Weight` 矩阵（不能复用 `Matrix`），有边的位置填 `randint(W_MIN, W_MAX)`
5. **派任务**：跳过起点和孤立点（`sum(Matrix[v]) == 0`），按 `Task_Pro = 0.5` 概率有件，有件再按 `Task_Pro_1 = 0.3` 分成优先件 P / 普通件 O

## 三、跑出来的结果（实测）

```
Lite1 = [0, 6, 6, 6, 9, 3, 5, 5, 2]
Lite2 = [6, 9, 8, 3, 5, 1, 4, 2, 7]
P(优先) = [3, 4]
O(普通) = [2, 5, 7, 9]
```

- 两个矩阵都是 10×10、对称、对角线为 0
- 权值全部落在 3~25，没有边的地方是 0

## 四、用 Java 还原的对照要点（重点）

| Python 写法 | Java 对应写法 | 注意 |
|---|---|---|
| `random.Random(SEED)` | `new Random(2024)` | **同一种子两边结果完全不同**，见下 |
| `rng.randint(3, 25)` | `rnd.nextInt(23) + 3` | Python 两端都含；Java 的 `nextInt(n)` 上界**不含** |
| `rng.shuffle(order)` | `Collections.shuffle(list, rnd)` | 要 `List<Integer>`，`int[]` 不行 |
| `rng.choice(in_tree)` | `in_tree.get(rnd.nextInt(in_tree.size()))` | |
| `[[0] * N for _ in range(N)]` | `new int[N][N]` | Java 二维数组自动填 0，不用初始化 |
| `zip(Lite1, Lite2)` | 按下标的 for 循环 | |
| `sum(Matrix[v]) == 0` | 遍历第 v 行累加 | |
| `print(list)` | `Arrays.toString(arr)` | 直接打印数组出来的是地址 |
| `list.append(x)` | `list.add(x)` | 用 `ArrayList<Integer>` |

**最容易踩的坑：随机数对不上**

```
python random.Random(2024).random()  →  0.470090718431  0.728264291423  0.303751358391
java   new Random(2024).nextDouble() →  0.618453632830  0.188298147636  0.930978814560
```

两边算法不同（Python 用梅森旋转，Java 用 48 位线性同余），**同一个种子生成不出同一个算例**。
所以 Java 还原后不要拿两边的输出逐行对比，应该二选一：

- 只比**结构指标**：边数 = 9、矩阵对称、权值落在 3~25、任务分成 P/O 两组
- 把 Python 生成的算例**导出成文件**，Java 直接读文件，两边跑同一份数据

取值范围可以对齐，实测两边都取得到两端：

```
python randint(3, 25) 范围:  3 ~ 25
java   nextInt(23) + 3 范围:  3 ~ 25
```

## 五、带出的通用结论

1. 随机算例生成器必须**固定种子**，否则算法既没法复现也没法对比
2. "先生成一棵树、再按概率补边"是生成连通图的常用套路，天然避免孤立点
3. 邻接矩阵和权值矩阵要**分开存**：一个有边但权值为 0 的图和"没有边"完全不是一回事，混用就分不清
4. 无向图只遍历上三角、赋值时两处都写，能避免重复处理同一条边

## 六、Java 还原的推进顺序（建议）

1. 先搭数据层：`int[][] matrix`、`int[][] weight`、`List<Integer> p`、`List<Integer> o`
2. 再搬随机逻辑：固定种子、洗牌、按概率补边、随机赋权
3. 到这一步应该能打印出结构一致的 10×10 路网（数值不必相同）
4. 最后往上叠投送算法（贪心 / 精确解），对应原项目里的 `greedy.py`、`exact.py`
