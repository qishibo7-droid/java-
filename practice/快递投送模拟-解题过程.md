## 一、这段代码在做什么

一次跑完六个阶段：

| 阶段 | 做什么 | 本次运行（SEED = 258） |
|---|---|---|
| 1 | 随机生成 10 节点生成树，保证连通 | 9 条边 |
| 2 | 按 `EXTRA_EDGE_P = 0.30` 概率补边 | 邻接矩阵 `Matrix` |
| 3 | 每条边随机赋权 3~25 | 权值矩阵 `Weight` |

## 二、零件一：Floyd-Warshall 求全源最短路

状态表每格存两样东西：

```python
D[i][j] = [最短距离, 完整路径]
```

| 步骤 | 做什么 |
|---|---|
| 1 | 初始化：`D[i][i] = [0, [i]]`；有边就填 `D[i][j] = [Weight[i][j], [i, j]]`；其余是 `INF` |
| 2 | 三层循环 `k → i → j`，把 `k` 当成中转站 |
| 3 | 若 `D[i][k] + D[k][j] < D[i][j]` 就更新，路径拼成 `p1 + p2[1:]` |

要点：

- 路径拼接里的 `p2[1:]` 是**去掉重复的中转点 k**——`p1` 结尾是 k、`p2` 开头也是 k
- 每格同时存距离和路径，后面就不用再回溯，直接用
- 复杂度 O(n³)，10 个节点 1000 次比较，随便跑

## 三、零件二：优先件的最快路线（全排列暴力搜索）

业务约束是**优先件必须最快送到**，所以先只考虑 P 集合。两个函数分工：

| 函数 | 干什么 |
|---|---|
| `best_end(v, stops, begin)` | 固定终点 v，把其余待送点**全排列**，选总路程最短的那个顺序 |
| `best_route(stops, begin)` | 让 stops 里每个点都当一次终点，取全局最快的那个 |

关键的一行是配对技巧：

```python
zip((begin,) + o, o + (v,))
# (begin,) + o  →  (0, 5, 6, 8)
# o + (v,)      →  (5, 6, 8, 4)
# 配对结果：(0,5) (5,6) (6,8) (8,4)
```

`(begin,)` 是**单元素元组**，`+` 是元组拼接（不是加法），这样就把"起点 + 中间顺序 + 终点"首尾接成一段段路径，再挨个查 `D` 表取距离。

代价是阶乘：n 个待送点就是 n! 种顺序。本次 4 个优先件 → 3! = 6 种顺序 × 4 个候选终点，秒出；优先件到 9 个就是 8! = 40320 × 9，就会明显变慢。

## 四、零件三：两阶段配送

| 阶段 | 送什么 | 起点 | 本次结果 |
|---|---|---|---|
| 第一阶段 | 优先件 P | 起点 0 | 终点 4，63 分钟，顺序 `[0, 5, 6, 8, 4]` |
| 第二阶段 | 普通件 O | 第一阶段的终点 | 终点 1，37 分钟，顺序 `[4, 3, 1]` |

两个工具函数：

- `unpack(route)`：把"停靠顺序"展开成"实际走过的每个节点"——停靠点之间走的是 `D` 里记录的最短路，中间可能穿过别的节点
- `find_passed(route, O)`：把路上经过的普通件节点挑出来，算"顺路已送"

- 节点 3 在第一阶段顺路送过，第二阶段路线里又出现了一次

## 六、Java 还原对照要点

| Python | Java | 注意 |
|---|---|---|
| `itertools.permutations(others)` | 没有现成的，**要自己写回溯**（DFS 或 visited 数组） | Java 标准库没有全排列 |
| `min(permutations, key=...)` | 回溯过程中顺手维护最小值 | 不用先把所有排列存下来 |
| `INF = float("inf")` | `Integer.MAX_VALUE / 2` | 直接 `MAX_VALUE` 相加会溢出成负数 |
| `D[i][j] = [距离, 路径]` | 拆成 `int[][] dist` + `List<Integer>[][] path`，或自定义小类 | |
| `p1 + p2[1:]` | `new ArrayList<>(p1); addAll(p2.subList(1, p2.size()))` | 切片下标别忘边界 |
| `(begin,) + o` | 下标循环拼数组 | 元组拼接在 Java 里没有对应语法 |
| `zip(a, b)` | 按下标的 for 循环 | |
| `random.Random(SEED)` | `new Random(seed)` | 同种子两边序列不同（见上一版笔记） |
| `rng.randint(3, 25)` | `rnd.nextInt(23) + 3` | Python 两端都含，Java 上界不含 |
| `print(list)` | `Arrays.toString()` / `list.toString()` | |

## 七、还原时要注意的边界情况

1. **优先件可能一个都没有**（`Task_Pro_1` 调小就会出现）：这时第一阶段整段跳过，但最后照样要拿第一阶段的时间去相加，变量还没赋值就会直接报错。Java 里把两个阶段的时间**都先初始化成 0** 再累加
2. **第二阶段只该送"还没送掉"的普通件**：顺路已经派过的节点要从 O 里去掉，否则会重复跑一趟
3. **优先件为空时，普通件不能被跳过**：判断要不要第二阶段，依据应该是"O 里还有没有没送的"，而不是"第一阶段的路上有没有顺路送过"
