# example2 解题过程总结

对应代码：`practice/example2.java`
涉及知识点：双层 for 循环、`print` 与 `println` 的区别、转义字符 `\t` `\n`、`continue`

## 一、这道题在做什么

打印 9 行乘法口诀表，第 i 行从 `i×i` 递减到 `i×1`：

```
1×1=1
2×2=4	2×1=2
3×3=9	3×2=6	3×1=3
```

## 二、通用过程：打印表格类题目的四步

| 步骤 | 做什么 | 本例 |
|---|---|---|
| 1 | 数清楚**有几行** | 9 行 |
| 2 | 想清楚**每一行打印什么** | 第 i 行：i×i、i×(i-1)、…、i×1 |
| 3 | 外层循环控行，内层循环控行内元素 | 外层 `for (i)`，内层 `for (a)` |
| 4 | 行内用 `print` 加分隔符，行尾再补一个 `\n` | `\t` 分隔，最后一项打 `\n` |

## 三、代码骨架

```java
for (int i = 1; i <= 9; i++) {
    for (int a = i; a > 0; a--) {
        if (a == 1) {
            System.out.print(i + "×" + a + "=" + i * a + "\n");
            continue;   // 跳过下面那句，否则行尾会多出一个制表符
        }
        System.out.print(i + "×" + a + "=" + i * a + "\t");
    }
}
```

## 四、知识点对照

| 写法 | 作用 |
|---|---|
| `print` | 打印后**不换行**，用来拼出同一行 |
| `println` | 打印后换行 |
| `\t` | 制表符，让同一行的算式对齐 |
| `\n` | 换行符，写在字符串里同样能换行 |
| `continue` | 跳过本次循环剩下的语句；这里用来避开行尾多余的 `\t` |

等价写法：不用 `continue`，把内层条件改成 `a > 1`，最后单独补一条打印：

```java
for (int a = i; a > 1; a--) System.out.print(i + "×" + a + "=" + i * a + "\t");
System.out.print(i + "×1=" + i + "\n");
```

## 六、解题固定套路

1. 打印类题目先在纸上**写出前 3 行**，规律一眼就看出来
2. 行数 → 外层循环；行内元素个数 → 内层循环
3. 行内不要换行（`print`），只在行尾换（`\n`）
4. 想让列对齐就用 `\t`，不要用手打空格
5. 最后一项最容易出错，写完先数一数行尾有没有多余的制表符
