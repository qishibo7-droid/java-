# 2026-09-13 学习记录

## 自增自减

- `a++`（后置）先出结果再自增；`++a`（前置）先自增再出结果
- `int b = 1; int c = ++b;` → `c` 是 2；`c = b++;` → `c` 是 1 而 `b` 变 2
- 单独写一行时 `a++` 和 `++a` 效果一样，差别只在**参与运算**时体现

拆解练习 `int data1 = 8; int data2 = -data1++ + ++data1;`

```
-data1++   →  先取 -8，然后 data1 变成 9
++data1    →  data1 先变成 10，取 10
-8 + 10    →  data2 = 2
```

## 复合赋值运算符

`+=`、`-=`、`*=`、`/=`、`%=` 是缩写形式，和 Python 一致：

```java
data1 += 10;    // 等价于 data1 = data1 + 10
data1 *= 2;     // 等价于 data1 = data1 * 2
```

## 位运算符

```java
int a = 9, b = 3;   // a = 1001, b = 0011

a & b    // 0001 → 1    与：都为 1 才是 1
a | b    // 1011 → 11   或：有一个 1 就是 1
a ^ b    // 1010 → 10   异或：不同为 1，相同为 0
~127     // 10000000 → -128   取反（含符号位）
```

位移：

```java
1 << 1   // 00000001 → 00000010 = 2，左移 n 位等于 ×2ⁿ
```

- `<<` 左移、`>>` 带符号右移（空位按符号位填充，负数仍是负数）
- `>>>` 无符号右移，**空位一律补 0**，所以负数会变成正数

## 关系与逻辑运算符

```java
10 > 9              // true
9 < b && b < 15     // Java 不能写 9 < b < 15，必须用逻辑运算符拆开
!true               // false，非运算
条件 ? 结果1 : 结果2  // 三元运算符
```

**短路**：`&&` 和 `||` 会提前结束判断

```java
int data2 = 9;
boolean data3 = 10 < 9 && ++data2 > 2;
// 左边已经 false，&& 后面的 ++data2 根本不会执行 → data2 仍是 9
```

用 `&` 和 `|`（单个）则**不会短路**，两边都会算：

```java
data3 = 10 < 9 & ++data2 > 2;   // 这次 ++data2 执行了 → data2 变成 10
```

## 运算符优先级

| 优先级 | 运算符 | 结合性 |
|---|---|---|
| 1 | `()` | 左→右 |
| 2 | `~ ! + -`（正负号）、强制转换、`++ --` | 右→左 |
| 3 | `* / %` | 左→右 |
| 4 | `+ -` | 左→右 |
| 5 | `<< >> >>>` | 左→右 |
| 6 | `> < >= <=` | 左→右 |
| 7 | `== !=` | 左→右 |
| 8 | `&` | 左→右 |
| 9 | `^` | 左→右 |
| 10 | `\|` | 左→右 |
| 11 | `&&` | 左→右 |
| 12 | `\|\|` | 左→右 |
| 13 | `?:` | 右→左 |
| 14 | `= += -= *= /= %= &= \|= ^= <<= >>= >>>=` | 右→左 |
