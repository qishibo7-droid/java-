## break 与 continue

```java
for (int i = 0; i < 5; i++) {
    if (i == 3) continue;   // 跳过本次 → 打印 0 1 2 4
    System.out.println(i);
}
for (int i = 0; i < 5; i++) {
    if (i == 3) break;      // 结束整个循环 → 打印 0 1 2
    System.out.println(i);
}
```

- `continue`：跳过本次循环剩下的语句，直接进入下一轮
- `break`：跳出整个循环，后面的轮次都不再执行
- 撞上条件的那一次本身也不会执行（`i == 3` 时不会打印 3）

## 嵌套循环里的 break / continue

- 不带标记时，只作用于**最近的那一层循环**
- 内层 `break` 之后，外层循环照常进入下一轮（`i` 循环里套 `j` 循环，每轮只打印 `j=0`、`j=1`）
- 带标记就能指定作用对象：

```java
outside: for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 2) break outside;   // 直接终止外层 i 循环
        System.out.println("j=" + j);
    }
}
```

- 标记名在互不嵌套的两处可以重复使用（同一个文件里用了两次 `outside`）

## while 与 do-while

```java
int i = 0;
while (i != 5) { System.out.println(i); i += 1; }      // 先判断，再执行

i = 0;
do { System.out.println(i); i += 1; } while (i != 5);  // 先执行一次，再判断
```

- 两者都输出 0 1 2 3 4，区别是 `do-while` **至少执行一次**
- `do-while` 结尾的分号不能少：`} while (i != 5);`
- 循环体里每条语句结尾也要有分号

## 死循环

for (;;) { }   // 三个表达式全省略，表达式2 默认为 true
