## switch 表达式（新式写法）

```java
int score = 0;
String level = switch (score) {
    case 10, 9 -> "等级为a";
    case 6, 7, 8 -> "等级为b";
    case 3, 4, 5 -> "等级为c";
    default -> {
        System.out.print(score);
        System.out.print("不及格\n");
        yield "等级为d";
    }
};
System.out.println(level);   // 输出 0不及格 / 等级为d
```

- 用 `->` 代替 `:`，箭头后面直接写结果，**不用写 break**，也不会穿透
- 一个 `case` 可以并列多个值：`case 10, 9 ->`
- `switch` 可以当**表达式**用，整个结果直接赋给变量
- 分支里要多条语句就用 `{}`，最后用 `yield` 把结果交出去
- `default` 不能少，否则编译器认为变量有可能没被赋值，直接编译错误

## for 循环

```
for (表达式1; 表达式2; 表达式3) 循环体
```

- 表达式1：循环开始前执行一次，通常用来定义循环变量
- 表达式2：每轮开始前判断，**结果必须是 boolean**，为 false 就结束循环
- 表达式3：每轮结束后执行，通常用来更新循环变量
- 三个表达式都可以省，`for (; i != 7; i += 1)` 照样能跑

案例（找数字 7）：

```java
int i = 0;
for (; i != 7; i += 1) System.out.println(i);   // 打印 0 到 6
if (i == 7) { System.out.println("找到了"); }
else { System.out.println("未找到"); }
```

- 循环变量定义在循环外面，循环结束后还能继续用，值停在让条件不成立的那一刻（这里是 7）

## 浮点数的相等比较

```java
boolean Data = (0.3F == 0.1F + 0.2F);   // true
0.1 + 0.2 == 0.3                        // false（double）
```

- 两组字面量一个相等一个不等，说明 `==` 比较浮点数**结果不稳定**，取决于二进制能不能凑齐
- 比较浮点数一律用误差范围：`Math.abs(a - b) < 1e-6`
- 结论：永远不要用 `==` 判断两个浮点数是否相等
