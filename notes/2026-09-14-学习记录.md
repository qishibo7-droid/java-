# 2026-09-14 学习记录

## 代码块作用域

- `{}` 管的是**名字能不能用**，不管值的生命期
- 块内定义的变量，块外访问不到：`{ int b = 11; }` 之后的 `System.out.println(b);` 编译报「找不到符号」
- 块外定义的变量，块内改了会保留：

```java
int a = 10;
{
    ++a;
    System.out.println(a);   // 11
}
System.out.println(a);       // 11，改的是同一个 a
```

- Java 禁止在嵌套块里重复定义同名变量（C/C++ 可以）

## if 选择结构

- 不带 `{}` 时，`if` 只管紧挨着的那一条语句，多条语句要用 `{}` 圈起来
- 括号必须包住**整个条件**：

```java
if (score >= 60 && score <= 90) { }     // 正确
if (score >= 60) && (score <= 90) { }   // 错误：非法的表达式开始
```

- 报错原理：`if (...)` 的括号提前闭合，编译器以为 if 语句已结束，紧接着遇到 `&&` 就报错，并连带报「需要';'」「有 'if'，但是没有 'else'」
- Java 不支持连比，`60 <= score <= 90` 是编译错误
- 判断区间只能用 `&&`；写成 `||` 恒为 true（任何数要么 ≥60 要么 ≤90）
- `&&` 会短路，`&` 两边都算，`if` 里统一用 `&&`
- `else if` 链里前面的条件已经排除了后面的情况，区间可以省：

```java
if (score > 90)       { /* 优秀 */ }
else if (score >= 60) { /* 走到这里自动就是 60~90 */ }
else                  { /* 不及格 */ }
```

- 边界值最容易错，59 / 60 / 90 / 91 都试一遍

## switch 选择结构

```java
int data = 1;
switch (data) {
    case 1:
        data += 1;
        break;
    default:
        data = 0;
}
System.out.println(data);   // 2
```

- 匹配到 `case` 就进入，执行到 `break` 才跳出
- **穿透**：不写 `break` 会继续往下执行，不管后面的 `case` 是否匹配（三个分支都不写 break，`data` 会从 1 一路加到 4）
- 故意穿透可以合并分支：

```java
case 1:
case 2:
case 3:
    data = 100;
    break;
```

- `case` 后面只能是常量（字面量或 `static final`），变量不行
- `case` 表达不了区间，60~90 这种范围只能写 `if`
- 所有 `case` 都不匹配时走 `default`
