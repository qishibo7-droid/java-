## 取数位的通用套路

```java
int a = 0, b = 0, c = i;
for (; c != 0; c = c / 10) {
    a = c % 10;       // 取出当前最低位
    b += a * a * a;   // 用它做点事
}
```

- 取个位：`n % 10`；去掉个位：`n = n / 10`
- 两者配合循环，就能从低位到高位遍历每一位，位数未知也不用管
- 拆之前**要复制一份给临时变量**（`c = i`），否则原数被拆没了，最后没法再和原数比较
