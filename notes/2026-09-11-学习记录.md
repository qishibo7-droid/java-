## 基础语法结构

- 类的定义：`public class 类名 { }`，文件名必须与 public 类名一致
- 程序入口：`public static void main(String[] args)`
- 三种注释：`//`、`/* */`、`/** */`
- 输出：`System.out.println(...)`

## 基本数据类型

| 类型 | 位数 | 取值范围 |
|---|---|---|
| byte | 8 | -128 ~ 127 |
| short | 16 | -32768 ~ 32767 |
| int | 32 | -2³¹ ~ 2³¹-1 |
| long | 64 | -2⁶³ ~ 2⁶³-1 |

规律：n 位有符号整数的范围是 **-2ⁿ⁻¹ ~ 2ⁿ⁻¹-1**。
正数最大值要 -1，是因为 0 占用了一个位模式；负数不用 -1，所以负数比正数多一个（byte 能到 -128）。

### 溢出：最大值 +1 会变成最小值 ⚠️

补码的环形结构导致的：最大值加 1 会**绕回最小值**，而且 **Java 不报错、不抛异常，静默给你一个错得离谱的结果**。

```java
int max = Integer.MAX_VALUE;    // 2147483647
int r1 = max + 1;               // 输出 -2147483648  ← 绕回最小值

int min = Integer.MIN_VALUE;    // -2147483648
int r2 = min - 1;               // 输出 2147483647  ← 反向同样绕回去

byte  b = 127;   b++;           // b 变成 -128
short s = 32767; s++;           // s 变成 -32768
```

以后写代码要注意：
- 求和、累加、计数时，先想清楚**会不会超过类型的上限**
- 需要更大范围就用 `long`
- 可以在运算前先判断，例如判断 `a > Integer.MAX_VALUE - b` 之后再相加，超了就别加

## 常量与类型转换

- `final` 修饰常量，赋值后不可修改
- 隐式转换只允许「小范围 → 大范围」：byte → short → int → long → float → double
- 反向必须显式强制转换，如 `(byte) b`
- Java 的整数类型全部有符号，**没有 unsigned**

## 与 Python 的对比

| | Python | Java |
|---|---|---|
| 类型 | 动态类型 | 静态强类型，必须声明 |
| 整数 | 任意精度，不溢出 | 定长位数，溢出静默回绕 |

## 二进制与米奇试药

经典小白鼠试毒问题：n 只米奇能定位 2ⁿ 瓶药中的毒药，每只米奇代表二进制的一位。
1000 瓶需要 10 只（2¹⁰ = 1024）。
对应知识点：位模式既是数值，也是编码。
